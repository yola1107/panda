# 05: 慢客户端断开

**What to build:** 每条连接有一个有界发送队列。客户端读取过慢导致队列满时，Gate 断开该连接，消息不会被静默丢弃，其他连接不受影响。规格见 [M1 规格](../spec.md)。

**Blocked by:** 04 组合部署下按会话主动推送

**Status:** ready-for-agent

- [ ] 发送队列上限可以按入口配置。
- [ ] 客户端停止读取并持续收到推送时，队列满后连接被断开。
- [ ] 队列满时，发起推送的一方收到明确错误。
- [ ] 一个慢客户端不阻塞同一 Gate 上其他连接的收发。
- [ ] 断开后，该连接的队列和 goroutine 全部释放。
