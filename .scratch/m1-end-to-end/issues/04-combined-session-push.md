# 04: 组合部署下按会话主动推送

**What to build:** 在组合部署下，业务代码可以按会话发起主动推送，消息到达对应客户端，不需要客户端先发请求。规格见 [M1 规格](../spec.md)。

**Blocked by:** 03 组合部署下的登录、请求、应答与通知

**Status:** resolved

- [x] Handler 和业务代码都能按会话发起主动推送。
- [x] 主动推送携带数字路由，RequestID 为 0。
- [x] 推送只到达目标会话，同一 Gate 上的其他会话收不到。
- [x] 目标会话已关闭时，推送返回明确错误，不会静默成功。
- [x] Go 参考客户端按数字路由分发主动推送回调。
- [x] 同一逻辑服务经 Protobuf 和 JSON 两个入口建立会话时，Node 按目标会话描述中的 Codec 编码推送，各客户端均能正确解码。

本任务建立推送运行时和回调接入能力；类型化推送分发代码由任务 07 生成，任务 08 验证业务调用方无需手写路由号或解码。
