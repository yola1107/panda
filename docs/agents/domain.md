# Domain Docs

本仓库采用 single-context，所有服务共用一套领域文档。

## 读取规则

探索代码或讨论领域概念前：

- 若根目录 `GLOSSARY.md` 存在，先读取其中的领域术语。
- 若 `docs/adr/` 存在，读取与当前工作相关的 ADR。
- 文件不存在时直接继续，不将缺失作为问题，也不提前创建占位文件。
- 术语或决策实际明确后，由 `domain-modeling` 按需建立文档。

## 文档位置

- 术语表：`GLOSSARY.md`。
- 架构决策：`docs/adr/<NNNN>-<slug>.md`。

## 使用规则

- 任务标题、设计讨论、测试名称等使用术语表定义的词汇，避免引入同义词漂移。
- 遇到缺失术语时，先判断是否确有领域概念需要命名，再记录给 `domain-modeling`。
- 提议与已有 ADR 冲突时，明确指出冲突的 ADR 和重新评估的理由。
