# 提交约定

- 按用户指定范围提交。未指定范围时，有暂存内容就只提交暂存；否则提交本任务改动。
  仅暂存明确路径，保留部分暂存边界。
- 提交前确认分支和 HEAD，复审待提交差异，按 [完成条件](../../AGENTS.md#完成条件) 验证暂存版本，执行 `git diff --cached --check`。
  有冲突或未完成的 Git 操作时，停止并报告。
- 保持原子提交，源文件与生成产物一起提交。
  消息格式为 `<type>(<scope>): <中文摘要>`，type 使用 `feat|fix|refactor|docs|test|chore`。
  必要时在正文说明原因与验证结果。
- 正常执行 hooks 和签名。失败时保留现场并报告，重试前确认是否已生成提交。
  提交后核对内容，报告 SHA、验证结果与剩余改动。
