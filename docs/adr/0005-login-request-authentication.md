# 通过登录请求完成认证

连接建立后处于未认证状态，Gate 只放行心跳与逻辑服务声明的登录请求，认证超时仍未登录则断开连接。
Gate 先按逻辑服务选定 Node，再转交登录请求；分离部署时通过 Kratos 服务发现选定。
登录转交只带连接上下文，不携带尚不存在的会话 ID 或可信用户身份，字段见 ADR 0006。
Node 决定是否通过，并在独立于客户端应答 payload 的内部认证结果中返回绑定用户；Gate 无需解码业务 payload。
Gate 仅在连接仍未认证、该次登录仍有效时原子创建会话并绑定用户，后续请求与通知固定发往这个 Node，并附带可信用户身份。
认证失败、登录超时或连接关闭时不创建会话；迟到的登录结果不得创建或变更会话。登录 Handler 不获得已认证会话，也不能把客户端声明的身份当作可信身份。

WebSocket 握手不携带认证凭证：浏览器无法为 WebSocket 设置自定义 header，放入 query 又容易写进访问日志，统一走登录请求也让 TCP 与 WebSocket 一致。
