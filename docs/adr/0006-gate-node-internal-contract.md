# Gate 透传 payload，Node 直接回推持有连接的 Gate

Gate 与 Node 之间使用两个不对客户端暴露的内部 Proto 服务：

- Gate → Node：转交连接上下文、可选的会话信息、数字路由、消息类型与原始 payload 字节。请求返回应答 payload 与错误，登录请求另返回结构化认证结果；通知不返回业务结果。
- Node → Gate：主动推送携带会话 ID、数字路由与 payload 字节。

## 转交上下文与登录结果

连接上下文包含 Gate 实例标识、连接标识、逻辑服务标识和 Codec 标识。逻辑服务与 Codec 由 Gate 根据入口配置写入，同一连接内固定，不接受客户端 payload 中的值覆盖。
未认证的登录转交不含会话 ID 和可信用户身份；认证后转交增加这两项。Node 按逻辑服务选择路由表，并校验该服务是否支持指定 Codec，不支持时返回明确错误。
登录成功时，内部认证结果必须包含绑定的用户；登录失败时不返回可绑定的身份。该结果不编码进客户端业务 payload，Gate 按 ADR 0005 完成绑定。

Gate 不解码 payload，由 Node 按入口的编码器解码，因此 Gate 不认识任何业务消息，新增路由无需修改 Gate。
Node 使用同一 Codec 编码应答；主动推送按目标会话描述中的 Codec 编码，不能使用 Node 的全局默认 Codec 代替。
认证后的会话描述保留 Gate 实例标识、会话 ID、逻辑服务与 Codec，Node 据此直接调用持有连接的 Gate；分离部署走 Kratos RPC，组合部署走本地调用。
按会话的主动推送因此不依赖在线索引。

## 超时与取消

每次转交调用使用以连接生命周期为父级、具有执行期限的 Context，本地调用与 RPC 都将期限和取消传递到 Handler。
连接关闭、服务停止或执行超时后取消相关调用；迟到结果不得再作为成功应答或认证结果使用。取消不表示业务副作用已回滚，也不触发自动重试。
通知的转交可以返回过载等内部接收错误，供 Gate 执行连接策略，但不生成客户端业务应答。执行上限及过载策略见 M1 规格。
